FlashcardsApp 🃏

Настольное JavaFX-приложение для создания, организации и изучении учебных карточек (интервальное/визуальное повторение). Приложение ориентировано на преподавателей и учеников, поддерживая мульти-профильную структуру, гибкие темы оформления и плавные анимации перелистывания.

---

## 🌟 Ключевые возможности

* **Мультипрофильность:** Создание и управление несколькими профилями учеников в одном приложении.


* **Управление колодами и карточками:**
* Индивидуальные обложки для колод.


* Копирование колод между учениками.


* Поворот карточек по клику/пробелу и навигация с клавиатуры (стрелки `←` / `→`).




* **Импорт и Экспорт:**
* Совместимость с CSV-файлами (поддерживает разделители `,` и `;`).


* Форматирование файла с UTF-8 BOM для корректного отображения текста в Excel.




* **Кастомизация и Интерфейс:**
* Набор встроенных цветовых тем (`LIGHT`, `DARK`, `NORDIC`, `SAGE`, `PASTEL`, `OCEAN`).

* Кастомные стилизованные диалоговые окна и контекстные меню.

* Плавные анимации задержки при загрузке и 3D-переворота карточек (`RotateTransition`).


* **Надежность данных:** Автоматическое сохранение состояния приложения в `data.json` и создание бэкапов с метками времени при каждом запуске.

## 🚀 Запуск и сборка

### Требования

* JDK 21 или выше


* Apache Maven 3.8+



### Разработка и запуск из IDE

Запустите класс `com.example.flashcardsapp.Launcher`.

### Сборка Fat-JAR

Для создания исполняемого `.jar` файла со всеми зависимостями выполните:

```bash
mvn clean package

```

Скомпилированный файл будет сохранен по пути: `target/FlashcardsApp.jar`.

Запуск собранного JAR-файла:

```bash
java -jar target/FlashcardsApp.jar

```

### Сборка Windows `.exe` инсталлятора

Приложение автоматически упаковывается в `.exe` при выполнении фазы `package` через утилиту `jpackage`:

```bash
mvn clean package -DskipTests

```

Выходной файл установки `Flashcards-1.2.0.exe` будет создан в корне проекта.

## 💾 Хранение данных

Файлы конфигурации и колод создаются автоматически при первой сессии:

* **Windows:** `%APPDATA%\MyFlashcardsApp\`

* **macOS:** `~/Library/Application Support/MyFlashcardsApp/`

* **Linux:** `~/.config/MyFlashcardsApp/`
